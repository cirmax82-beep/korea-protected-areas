# 보호구역 종합포털

국내 생물·환경 관련 보호구역을 지도에서 보고, 구역별·종류별 경계를 SHP·GeoJSON·KML·GeoPackage로 내려받는 공개 포털입니다.
경계는 국토교통부 브이월드를 먼저 쓰고, 브이월드에 없는 종류와 빠진 구역은 한국보호지역 통합DB(KDPA)로 채웁니다.

- 주소: https://protect.biogrideia.com/
- 같은 주제를 시군구별 표로 정리한 사이트: https://zone.biogrideia.com/
- 새 주소는 호스팅케이알 DNS의 CNAME 레코드(`protect` → `cirmax82-beep.github.io`)로 연결됩니다.

## 사업지 분석(`#analyze`)

주소·좌표·지도 그리기·파일(SHP·GeoJSON·KML·DXF)로 사업지를 정하고 반경(0.1~20 km)을 고르면, 반경 안 보호구역마다 최단 이격거리·방향·관계(겹침·통과·포함)·겹침 넓이를 계산하고 결과를 SHP(zip)·GeoJSON·KML·CSV로 한 번에 내려받습니다(`js/analyze.js`).

- 계산은 모두 브라우저 안에서 하며, 올린 파일은 어디에도 보내지 않습니다. 주소 검색만 국토교통부 브이월드 검색 API(못 찾으면 오픈스트리트맵 Nominatim)에 검색어를 보냅니다.
- 브이월드 인증키는 저장소에 넣지 않고, 배포할 때 저장소 비밀값 `VWORLD_KEY`로 `js/config.js`를 만들어 넣습니다(브라우저에서 쓰는 키라 배포된 사이트에서는 보입니다. 브이월드에 등록한 서비스 주소에서만 쓰도록 되어 있습니다). 로컬에서 시험할 때는 `work/vworld_key.txt`로 같은 파일을 만들어 씁니다(저장소에 올라가지 않음).
- 거리·넓이: 사업지 중심 기준 국지 평면(타원체 보정)에서 원본 해상도 경계(`data/area`)로 계산합니다.
- 좌표계: .prj를 직접 풀어 바꾸며, Bessel(옛 한국 측지계) 좌표계에는 좌표 이동값을 붙입니다. .prj가 없으면 고른 좌표계(기본 EPSG:5186)를 씁니다.
- 내려받는 SHP는 WGS84 또는 EPSG:5186·5179·5185·5187·5188로 저장할 수 있고, 반경 경계에서 잘라 담을 수도 있습니다.
- 필요할 때만 불러오는 도구: turf 7.1.0(겹침·버퍼), shpjs 4.0.4(SHP 읽기), proj4 2.9.0(좌표계), JSZip 3.10.1(압축).

## 담은 보호구역(27종)

`tools/layers.py`가 기준입니다.

| 묶음 | 종류 |
|---|---|
| 자연·생태 보호구역 | 야생생물보호구역, 습지보호지역, 연안습지보호지역, 생태·경관보전지역\*, 특정도서\*, 국립·도립·군립공원, 산림보호구역, 백두대간보호지역, 기타 보전지역(자연휴양림·수목원 등)\* |
| 물·환경 규제지역 | 상수원보호구역, 수변구역\*, 수질보전 특별대책지역\*, 자연환경보전지역, 도시자연공원구역, 보호지구, 자연경관지구, 개발제한구역, 대기환경규제지역 |
| 국가유산 | 국가유산 보호구역, 천연기념물·명승\*, 전통사찰보존구역 |
| 해양·연안 | 보전연안해역, 해양보호구역, 환경보전해역\*, 수산자원보호구역 |

\* 표는 브이월드에 없어 KDPA로만 만든 종류입니다. 나머지도 브이월드에 빠진 구역은 KDPA로 보충합니다(같은 종류의 브이월드 구역과 절반 넘게 겹치면 넣지 않음). `tools/layers.py`의 `kdpa` 항목이 연결표입니다.

브이월드 해양보호구역은 2018년 11월 기준이라 그 뒤 지정분은 KDPA로 채웠습니다. 생태자연도 1등급 권역처럼 두 자료 모두에 없는 구역은 넣지 못했습니다.

## 자료와 이용 조건

- 경계: 국토교통부 브이월드(디지털트윈국토) 2D 데이터 API. 국토교통부 저작물은 출처를 밝히면 자유롭게 이용할 수 있습니다(브이월드 저작권정책).
- 보충 경계: 한국보호지역 통합DB(KDPA, https://www.kdpa.kr)의 전국 보호지역 SHP(WDPA 등재 기준). `tools/fetch_kdpa.py`로 받습니다. 구역마다 출처(SOURCE)를 적습니다.
- 구역: 공원·연안습지는 이름별, 그 밖의 레이어는 세부 구분 + 시도 + 시군구 + 고시 연도·번호별로 조각을 묶었습니다. 국가유산은 원자료의 문화재 이름으로 묶었습니다.
- 경계는 참고 자료이며 법적 효력이 없습니다.

## 파일

- `data/index.json`: 레이어와 구역 목록
- `data/map/<레이어>.json`: 지도 표시용(간소화)
- `data/area/<구역 id>.json`: 구역별 원본 해상도 경계(사이트에서 SHP·GeoJSON·KML로 바꿔 내려받음, `js/shpwrite.js`)
- 종류별 전체 SHP·GeoJSON(zip)과 전체 GeoPackage는 저장소가 커지지 않게 릴리스 `data-latest`에 올립니다.

## 갱신

브이월드는 해외 IP 접속을 막아 GitHub 서버에서는 받을 수 없습니다. 국내 컴퓨터에서 갱신합니다.

1. 처음 한 번: `인증키 저장.bat`을 더블클릭해 브이월드 인증키(서비스 URL `https://protect.biogrideia.com`)를 `work/vworld_key.txt`에 저장합니다. 이 파일은 저장소에 올라가지 않습니다.
2. 갱신: Git Bash에서 실행합니다(받기 → 가공 → 올리기 → 릴리스 파일 교체).

```bash
bash tools/update.sh
```

필요한 파이썬 패키지: geopandas, pyogrio, shapely, pyproj.
