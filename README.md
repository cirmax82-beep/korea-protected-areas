# 보호구역 종합포털

국내 생물·환경 관련 보호구역(야생생물보호구역, 습지보호지역, 국립·도립·군립공원, 산림보호구역, 백두대간보호지역, 상수원보호구역, 국가유산 보호구역, 보전연안해역 등)을 지도에서 보여 주고, 구역별·종류별 경계를 SHP·GeoJSON으로 내려받을 수 있게 하는 공개 포털입니다(준비 중).

- 주소(예정): https://protect.biogrideia.com/
- 같은 주제를 시군구별 표로 정리한 사이트: https://zone.biogrideia.com/

## 자료

- 경계: 국토교통부 브이월드(디지털트윈국토) 2D 데이터 API — 용도지역지구(토지이용규제) 및 자연공원·연안 레이어. 국토교통부 저작물은 출처를 밝히면 자유롭게 이용할 수 있습니다(브이월드 저작권정책).
- 레이어 목록: `tools/layers.py`

## 자료 받기

브이월드 인증키(서비스 URL `https://protect.biogrideia.com`)가 필요합니다. 인증키는 저장소 비밀값 `VWORLD_KEY`에만 둡니다.

```bash
VWORLD_KEY=인증키 python tools/fetch_vworld.py
```
