# 보호구역 종합포털

국내 생물·환경 관련 보호구역을 지도에서 보고, 구역별·종류별 경계를 SHP·GeoJSON·KML·GeoPackage로 내려받는 공개 포털입니다.

- 주소: https://protect.biogrideia.com/
- 같은 주제를 시군구별 표로 정리한 사이트: https://zone.biogrideia.com/
- 새 주소는 호스팅케이알 DNS의 CNAME 레코드(`protect` → `cirmax82-beep.github.io`)로 연결됩니다.

## 담은 보호구역(17종)

`tools/layers.py`가 기준입니다.

| 묶음 | 종류 |
|---|---|
| 자연·생태 보호구역 | 야생생물보호구역, 습지보호지역, 연안습지보호지역, 국립·도립·군립공원, 산림보호구역, 백두대간보호지역 |
| 물·환경 규제지역 | 상수원보호구역, 자연환경보전지역, 도시자연공원구역, 보호지구, 개발제한구역, 대기환경규제지역 |
| 국가유산 | 국가유산 보호구역, 전통사찰보존구역 |
| 해양·연안 | 보전연안해역 |

생태·경관보전지역, 특정도서, 해양보호구역, 수산자원보호구역은 브이월드에 경계가 없어 아직 넣지 못했습니다.

## 자료와 이용 조건

- 경계: 국토교통부 브이월드(디지털트윈국토) 2D 데이터 API. 국토교통부 저작물은 출처를 밝히면 자유롭게 이용할 수 있습니다(브이월드 저작권정책).
- 구역: 공원·연안습지는 이름별, 그 밖의 레이어는 세부 구분 + 시도 + 시군구 + 고시 연도·번호별로 조각을 묶었습니다. 국가유산은 원자료의 문화재 이름으로 묶었습니다.
- 경계는 참고 자료이며 법적 효력이 없습니다.

## 파일

- `data/index.json`: 레이어와 구역 목록
- `data/map/<레이어>.json`: 지도 표시용(간소화)
- `data/area/<구역 id>.json`: 구역별 원본 해상도 경계(사이트에서 SHP·GeoJSON·KML로 바꿔 내려받음, `js/shpwrite.js`)
- 종류별 전체 SHP·GeoJSON(zip)과 전체 GeoPackage는 저장소가 커지지 않게 릴리스 `data-latest`에 올립니다.

## 갱신

브이월드는 해외 IP 접속을 막아 GitHub 서버에서는 받을 수 없습니다. 국내 컴퓨터에서 갱신합니다.

1. 처음 한 번: `인증키 저장.bat`을 더블클릭해 브이월드 인증키(서비스 URL `https://protect.biogrideia.com`)를 `work/vworld_key.txt`에 저장합니다. 이 파일은 저장소에 올라가지 않습니다.
2. 갱신: Git Bash에서 실행합니다(받기 → 가공 → 올리기 → 릴리스 파일 교체).

```bash
bash tools/update.sh
```

필요한 파이썬 패키지: geopandas, pyogrio, shapely, pyproj.
